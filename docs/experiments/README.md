# Godot proposal review

This folder's parent file, `GODOT_PROPOSAL_REVIEW.md`, reviews the proposed Godot NPC perception, Jolt, Utility AI/GOAP and world-streaming ideas. It includes a corrected standalone reference and a test gate.

Nothing in this document automatically adds Godot to the active React/Three.js build or modifies the Unity/Cesium project. The GDScript reference has not been compiled in a Godot editor during this audit. Keep the project runtime unchanged until a controlled vertical-slice test proves a migration is worth the cost.
