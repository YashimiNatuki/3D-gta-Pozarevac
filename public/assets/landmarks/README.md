# City landmark models

This folder is used by the city-data feature branch for stylized GLB models such as the hospital exterior, Stari Korzo block and Vašarište stadium.

The models are game assets, not official architectural drawings or survey-grade photogrammetry. Before use, record for each asset:
- origin/source and generation method;
- license and redistribution status;
- units, scale, pivot, up-axis and forward orientation;
- bounding box and intended geographic anchor;
- material/texture size and LOD strategy;
- collision proxy separate from the visual mesh;
- load fallback and performance cost.

Verify current branch availability and checks before expecting these models in the production/default build.
