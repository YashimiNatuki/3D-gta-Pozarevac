# Intro video asset

Place the supplied game intro video at:

`public/videos/GameIntro_Pozarevac_ThugLife.mp4`

The game uses this exact path as its packaged startup intro. If it is absent, the startup screen falls back to the in-game cyber-matrix title card and offers a local MP4/WebM source picker. Locally uploaded object URLs are session-only and are deliberately not written to `localStorage`.

The original attachment was not copied into this repository because the source file is on the separate Windows device and its terminal is unavailable in this session. Do not replace it with a third-party sample video.
